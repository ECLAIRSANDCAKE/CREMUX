# Security

## Reporting a vulnerability
Open a private report under the repository's **Security → Report a vulnerability**. Please do not post exploits in public issues.

## Responsible use
Crémux includes reverse-engineering tools. Use them only on software you own or are authorized to analyze, and follow the law and license terms that apply to you.

## Data handling
- API keys and the GitHub token are encrypted with the Android Keystore and sent only to the provider you chose.
- AI-proposed commands require your approval by default. The optional auto-run mode is a best-effort filter, not a sandbox.
