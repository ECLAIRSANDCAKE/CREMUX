# Contributing

1. Open an issue first for anything larger than a small fix.
2. Fork, create a branch, and keep changes focused.
3. Build with GitHub Actions or locally (see [docs/BUILD.md](docs/BUILD.md)) and test on a device.
4. Open a pull request using the template.

Issues about packages installed inside the app belong in [termux-packages](https://github.com/termux/termux-packages). Never commit API keys, tokens or keystores.
